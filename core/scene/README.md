# Core Scene Examples

This folder contains core MotionLoom examples for the `scene` domain.

Use each example by opening its `main.motionloom`, copying the full content, and pasting it into the Anica VFX / MotionLoom page.

Generated indexes live in `../../browse/`.

## Basic rendering comparisons

These static examples use the same two-second, 1920 x 1080 Scene setup.
Compare them at the same preview scale to isolate text, compositing, mask,
matte and primitive edge rendering.
