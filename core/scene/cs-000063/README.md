# Precompose Layer Text

ID: `cs-000063`

Type: `core`

Domain: `scene`

Define reusable text artwork in a Precompose resource.
Render that source through a Layer and compare it with direct text.

Open `main.motionloom`, copy its complete content, and paste it into the MotionLoom editor.
The example is static for two seconds at 30 fps and 1920 x 1080.

Compare the five related examples at the same preview scale. They isolate
rendering paths; they do not enable a 3D anti-aliasing preset.
