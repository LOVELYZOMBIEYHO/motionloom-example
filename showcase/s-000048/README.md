# Dual Cursed Eye Path Animation

This showcase builds a dramatic twin-eye shot using only MotionLoom scene primitives.

- The left eye uses a red rotating three-blade iris made from Path nodes.
- The right eye uses concentric violet rings, spokes, and pulsing aura layers.
- Both eyes use named groups for scene controls, animated gaze shifts, blink compression, and glow pulses.

The design is intentionally original and avoids external image assets so it remains editable as DSL Path animation.
