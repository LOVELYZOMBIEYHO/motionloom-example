# Beyond the Last Meridian — Night Chart Prologue

Showcase 69 is a 16.5-second, five-act motion-graphics prologue drawn entirely
with MotionLoom vector DSL. An indigo nautical chart draws itself, a golden
route crosses the sea, a storm gathers, a lighthouse beam searches the dark,
and the final title surfaces.

## What it demonstrates

- advanced `Path` animation with `trimStart`, `trimEnd`, taper and
  `offsetPath`;
- a strict navy, gold, ivory, and teal material palette built from reusable
  gradients;
- deterministic procedural dust, scratches, stars, waves, and map marks with
  `Repeat` and seeded expressions;
- screen-blended light, a filtered lighthouse beam, title construction, and
  act-based transitions inside one Scene timeline;
- an explicit Process chain for spectral energy, bloom, and film grain.

## Structure

The visual storytelling remains vector-native and asset-free. This makes the
script portable across native, browser, and WASM renderers without external
downloads.

Load **Showcase 69** in the MotionLoom Graph UI to preview `main.motionloom`.
