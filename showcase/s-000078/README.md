# S78 — Primitive Asset Comparison Gallery

A 14-second gallery that places reusable primitive assets on a dark exhibition
floor and compares taper, bend, twist, smoothing, mesh quality, LOD and material
responses. The composition is self-contained and uses no external models or
textures, so each deformation can be inspected directly in MotionLoom.

The first row establishes the source shape and progressively isolates a single
modifier. Later rows combine compound assets, lighting and camera moves into a
small cinematic study. `main.motionloom` is the executable source of truth and
the generated `schema.json` records the exact tags and attributes it uses.
