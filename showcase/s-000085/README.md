# S85 — HeadAsset Portrait Turntable

S85 isolates the procedural `HeadAsset` as one large, readable portrait. It uses no GLB, texture, hair, eye spheres, nose primitive, mouth primitive, or attached ear primitive.

The 12-second studio turntable exposes the same continuous mesh from the front, three-quarter, profile, and rear views. Directional key, fill, and rim lighting reveal the eye sockets, brow, nose projection, cheeks, temples, mouth groove, jaw, chin, ear roots, and rear skull silhouette.

This showcase is intentionally not a comparison wall. Its purpose is to make the best current HeadAsset result large enough to judge, while keeping the remaining first-version limits visible: it provides a deformable head surface rather than production sculpting, separate eyeballs, teeth, tongue, strand hair, or elongated animal appendages.
